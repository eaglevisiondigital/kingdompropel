# Kingdom Propel V84 — Fixes Only

This update is intentionally limited to the public Propel brand-palette cleanup requested after V83.

## Included
- Replaces Foundations-style cream/brown treatment in the public Propel outcome cards with white/light Propel surfaces.
- Changes card headings to deep Propel navy/charcoal for stronger readability.
- Uses Propel green for numbering, checkmarks, icon accents and top borders.
- Restyles the Why Propel comparison cards to white + navy + Propel green.
- Restyles the Founding Momentum progression cards to white + navy + Propel green.
- Strengthens the connected ecosystem card typography/contrast.
- No approved copy, structure, navigation, routing, assets or functionality was redesigned.

## Install
Replace `/styles.css` with the included file after V83 is already installed.
