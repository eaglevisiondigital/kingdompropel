KINGDOM PROPEL BLUEPRINT — FOOTER-ONLY FIX

This update fixes only the footer at the end of the Propel Digital Ministry Blueprint.
It does not replace the front-facing Kingdom Propel homepage.

IMPORTANT

DO NOT upload these two files at the main repository root.
The index.html file must go inside the existing demo-blueprint folder.

UPLOAD INSTRUCTIONS

1. Open the kingdompropel repository on GitHub.

2. Click the existing demo-blueprint folder so the breadcrumb reads:
   eaglevisiondigital / kingdompropel / demo-blueprint

3. Click Add file, then Upload files.

4. Open the folder in this download named:
   UPLOAD-BOTH-FILES-INSIDE-GITHUB-DEMO-BLUEPRINT-FOLDER

5. Drag these two files into GitHub:
   index.html
   blueprint.css

6. Confirm GitHub is replacing the two existing files inside demo-blueprint.
   The destination must be:
   demo-blueprint/index.html
   demo-blueprint/blueprint.css

7. Commit with this message:
   Fix Blueprint footer layout and scaling

8. Wait for Netlify to finish the new deployment, then refresh:
   https://kingdompropel.com/demo-blueprint/

WHAT THIS FIX CHANGES

- Constrains the Propel logo to a normal footer size.
- Creates an intentional four-column desktop footer.
- Stacks the footer cleanly on tablets and phones.
- Restores readable text, links, spacing and contrast.
- Changes the Blueprint stylesheet version so browsers load the new CSS instead
  of reusing the broken cached footer.
- Leaves the front-facing homepage and all other Blueprint sections unchanged.
