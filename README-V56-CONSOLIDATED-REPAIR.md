# Kingdom Propel V56 — Consolidated Repair Update

This package intentionally consolidates the last several approved Propel updates instead of applying another narrow patch. It uses the V52 partner-platform expansion as the broader carry-forward base, overlays the V54/V55 Blueprint refinements, and then reapplies the latest approved Aug. 15–16 presentation corrections.

## Included / re-carried forward
- Propel website files carried forward from the V52 partner-platform expansion, including partner-platform positioning/resources updates.
- Blueprint V54/V55 Foundations Church palette, ecosystem architecture, closing sections, transparent logo assets, physical-to-digital, Ask Propel, Why Propel, implementation, recommendation, and future refinements.
- Re-applied Problem-page inverse cards: light Foundations fill with dark brown typography.
- Re-applied Ecosystem principle cards: light Foundations fill with dark typography.
- Rebuilt Ecosystem architecture readability: light master canvas, dark feature chips retained, stronger headings/journey labels, higher contrast.
- Restored the Digital Front Door animated website showcase using the newly supplied full Foundations Church homepage image. The Blueprint remains stationary while the homepage auto-scrolls inside the browser viewport; hover/focus pauses it. Mobile falls back to manual scrolling.
- Foundations palette remains in the Blueprint content sections; the fixed Propel sidebar/navigation remains Propel green.

## Installation
Upload/replace the files and folders in this package at the same paths in the existing Kingdom Propel Netlify project. This is intended as a consolidated update package, not a redesign of unrelated site files.
